# Simoo — Dairy Herd Genetics Simulator

Simoo is a web-based dairy herd genetics simulator developed for ANG 107 at UC Davis. Students manage a simulated dairy herd over multiple generations, making culling, mating, and selection decisions to improve genetic merit.

## Access the App

👉 [gmbog.shinyapps.io/Simoo](https://gmbog.shinyapps.io/Simoo)

## Quick Start

1. Set your **Random Seed** (assigned by instructor) and number of generations, then click **Initialize Herd**
2. Review your herd in the **My Herd** tab
3. Make culling, bull selection, and heifer decisions in the **Decisions** tab
4. Click **Advance Generation** and monitor progress in the **Progress** tab
5. **Save your progress** after each generation — the file is automatically named with the generation number (e.g., `simoo_save_2026-11-11_G2.rds`)

## Tips

- Work in groups of 2–3 to avoid overloading the server
- You cannot go back once you advance a generation — save first!
- Download your Herd Excel and take a screenshot of the Generation Summary before advancing
